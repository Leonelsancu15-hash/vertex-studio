# CAROLINES — Visual Direction

Personal-Styling-Atelier von Caroline Florett, Mode Villa, Theodor-Heuss-Straße 11, Bonn-Bad Godesberg.
Bestehende Website: https://www.carolines.world

## These

**Sichtbar machen, was längst da ist.**
Ein Villa-Atelier im späten Nachmittagslicht: ruhig, tastbar, ohne Beauty-Salon-Glanz.
Elfenbein trägt. Stein gliedert. Tinte spricht. Kobalt setzt einen einzigen Punkt. Messing bleibt ein Detail.

## Farben

| Rolle | Name | Hex | Anteil |
|---|---|---|---|
| Grund | Elfenbein | `#F4EFE6` | 60 % |
| Gliederung | Stein | `#D8D0C3` | 20 % |
| Schrift, dunkle Szenen | Tinte | `#14161C` | 15 % |
| Einziger Akzent (aus dem Logo) | Kobalt | `#090263` | 4 % |
| Detail (Hairlines, Ziffern) | Messing | `#B08D57` | 1 % |

Das Blau ist exakt aus dem bestehenden Logo (`Logo-CAROLINES-blue.png`) entnommen. Es ist deutlich dunkler als ein klassisches Kobalt; auf dunklem Grund wird für Text die aufgehellte Variante `#8F95FF` / `#A9B0FF` verwendet, Flächen und Buttons bleiben `#090263`.

## Typografie

| Rolle | Schrift | Schnitt | Einsatz |
|---|---|---|---|
| Display | Cormorant Garamond | 500, Italic 400 | Headlines, Zitate, Wortmarke, Zahlen |
| Text | Karla | 400 | Fließtext, Formular |
| Meta | Karla | 500, Versalien, Laufweite .16em | Labels, Navigation, Buttons |

Ein Akzentwort pro Headline in Cormorant Italic. Keine weiteren Schriften, keine Icons.

## Wortmarke

Die Original-Wortmarke ist eine gesperrte Serifen-Versalzeile mit Unterstrich in Kobalt. Auf der Website wird sie in Cormorant Garamond 600 mit .2em Laufweite und Hairline-Unterstrich nachgebaut (`.mark`, `.foot-mark`), damit sie in jeder Farbe und Größe scharf bleibt. Das Original-PNG (250 × 40 px) ist zu klein für den Web-Einsatz; eine Vektorfassung des Logos sollte von der Kundin angefordert werden.

## Bildsprache

Warme, filmische Fotografie ohne Menschen im Fokus: Fenster, Licht, Stoff, Messing, Stein. Keine Vorher-Nachher-Collagen, keine gestellten Model-Porträts, kein Pink, keine Verläufe. Die beiden Atelier-Motive sind KI-erzeugt und im Impressum als solche ausgewiesen; sie sind Platzhalter, bis echte Aufnahmen der Villa vorliegen.
